## JAVA

- class 호출 순서: static 변수 선언 및 초기화문 -> static 블록 -> main 메서드
- static 메서드는 오버라이딩이 불가능하다.
    - type이 부모 class일 경우 부모 class의 static 메서드가 호출된다.
    - static 함수 안에서는 static 변수만 접근 가능하다. (컴파일 에러 발생)
- 변수의 경우에도 부모 class의 변수가 호출된다.
- 일반적으로 다중 상속은 허락 안됨. 하지만 interface는 다중 상속이 가능하다.
- generic은 generic이나 object type을 매개변수로 받는 오버로딩 함수를 호출한다.
- 부모 생성자를 호출 안하면 기본 부모 생성자가 호출된다. (기본 부모 생성자가 없으면 컴파일 에러 발생)
- 부모 함수 안에서 실행되더라도 자식의 override된 함수가 호출된다.
- override 되지 않은 자식의 함수는 호출할 수 없다.

```java
int[][] arr = new int[][]{ {45, 50, 75}, {89}};

arr[0].length; // 3
arr[1].length; // 1
```
